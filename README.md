# hands_fireworks
An interactive canvas animation where you draw anything and a firecracker rocket travels along your drawing, burning it away in real time before exploding in a burst of sparks at the end.

Features:

Freehand drawing on canvas
Rocket follows the drawn path
Line erases progressively as the fire passes over it
Sparkle explosion at the end of each stroke

Built with: Vanilla HTML, CSS & JavaScript (Canvas API)
